本地处理

图片转换、优化、PDF 创建和 OCR 均在 Mac 本地完成。文件内容不会发送给 Studio 试用授权服务。访问文件、文件夹、摄像头和扫描仪需要授权；设置、历史记录、书签及包含名称、路径或错误的日志可能保存在本机。

Studio 购买

Studio 购买与恢复通过 Apple StoreKit 和 App Store 完成。应用接收交易和使用权限信息，但不获取 Apple 账户密码或银行卡信息。

试用资格

激活试用时，Apple 签名的应用交易及请求版本通过 HTTPS 发送。服务利用与账户关联的交易标识、应用身份和 Store 环境检查试用资格；该标识并非匿名。

Apple签名的应用交易标识符在App Store范围内与账户关联，但它不是Apple账户的密码或电子邮件地址。服务将核验交易、应用身份、商店环境和随请求发送的版本号。

服务及记录

服务运行于 Google Cloud Run，Apple CloudKit 保存包含服务器密钥派生标识、应用及环境信息和试用日期的资格记录。删除应用不会自动删除服务器记录。

CloudKit保存试用资格记录，其中包括由服务器密钥派生的标识符、应用ID、环境、记录版本以及试用开始和结束日期。该标识符可识别同一试用主体，不能视为匿名数据。记录用于授予或恢复试用、执行期限并防止重复激活或篡改。卸载应用不会自动删除服务器记录。

网站与连接

服务商可能处理 IP 地址、连接数据以及运行或安全日志。网站托管在 GitHub Pages，未额外加入分析脚本、广告跟踪器、Cookie 或外部字体。

在线请求会向服务提供者透露IP地址和常见连接信息。Google Cloud可能按配置处理运营与安全日志；GitHub Pages为安全目的记录访问者IP。本站未额外加入分析脚本、广告跟踪器、Cookie、外部字体或嵌入式联系表单。

支持邮件

如向支持邮箱发送邮件，Gmail 会处理地址、消息和可选附件，以便回复与调查。请避免发送敏感文件。

用途与保留

这些信息用于应用功能、购买、试用资格、支持与安全，不会出售或用于跨应用广告跟踪。试用记录可能在到期后保留；日志及邮件按照服务商政策保存。不承诺固定删除期限。

本地文件受设备设置和用户操作控制。试用资格记录在到期后仍可能保留，以执行限制和恢复试用。支持邮件和运营日志根据支持、安全、适用义务及服务提供者设置保存；本政策不承诺固定的自动删除期限。你可通过联系邮箱申请访问、更正或删除数据；某些记录可能需要保留。Apple负责付款和账户信息。

您的选择

您可以管理 macOS 权限、放弃试用，并向 kharliux@gmail.com 提出访问、更正或删除请求。部分安全记录可能需要保留。App Store 账户和付款由 Apple 管理。
