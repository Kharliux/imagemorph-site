ImageMorph · 隱私權

2026-10-14 · Carlos Rivera · kharliux@gmail.com

本機處理

圖片轉換、最佳化、PDF 製作和 OCR 均在 Mac 本機完成。檔案內容不會傳送至 Studio 試用授權服務。存取檔案、資料夾、相機和掃描器需要授權；設定、歷史紀錄、書籤及含名稱、路徑或錯誤的日誌可能儲存在本機。

Studio 購買

Studio 購買與回復透過 Apple StoreKit 和 App Store 完成。App 會收到交易與使用權限資訊，但不會取得 Apple 帳號密碼或信用卡資料。

試用資格

啟用試用時，Apple 簽署的 App 交易和請求版本透過 HTTPS 傳送。服務利用與帳號相關的交易識別碼、App 身分及 Store 環境確認試用資格；此識別碼並非匿名。

Apple簽署的App交易識別碼在App Store範圍內與帳號關聯，但不是Apple帳號密碼或電子郵件地址。服務會驗證交易、App身分、商店環境及隨要求傳送的版本。

服務與紀錄

服務在 Google Cloud Run 上運作，Apple CloudKit 保存含伺服器金鑰衍生識別碼、App 與環境資料及試用日期的資格紀錄。刪除 App 不會自動刪除伺服器紀錄。

CloudKit儲存試用資格紀錄，包括以伺服器金鑰衍生的識別碼、App ID、環境、紀錄版本及試用開始與結束日期。該識別碼可辨識同一試用主體，不能視為匿名資料。紀錄用於核發或恢復試用、實施期限並防止重複啟用或竄改。解除安裝App不會自動刪除伺服器紀錄。

網站與連線

服務供應商可能處理 IP 位址、連線資訊及作業或安全日誌。網站託管於 GitHub Pages，未額外加入分析程式、廣告追蹤器、Cookie 或外部字型。

線上要求會向服務供應商揭露IP位址及一般連線資訊。Google Cloud可能依設定處理作業和安全日誌；GitHub Pages為安全目的記錄訪客IP。本站未額外加入分析指令碼、廣告追蹤器、Cookie、外部字型或內嵌聯絡表單。

支援郵件

若向支援信箱寄信，Gmail 將處理地址、訊息及選擇性附件以回覆並調查問題。請避免寄送敏感檔案。

用途與保留

資訊用於功能、購買、試用資格、支援與安全，不會出售或用於跨 App 廣告追蹤。試用紀錄可能於到期後保留；日誌與郵件依供應商政策保存。不保證固定刪除期限。

本機檔案由裝置設定與使用者操作管理。試用資格紀錄到期後仍可能保留，以實施限制和恢復試用。支援郵件及作業日誌依支援、安全、適用義務和供應商設定保存；本政策不承諾固定的自動刪除期限。可透過聯絡信箱要求存取、更正或刪除資料；部分紀錄可能需要保留。Apple負責付款和帳號資訊。

您的選擇

您可管理 macOS 權限、選擇不使用試用，並透過 kharliux@gmail.com 要求存取、更正或刪除。部分安全紀錄可能需要保留。App Store 帳號和付款由 Apple 管理。
