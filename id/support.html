Pertanyaan umum

Mengapa optimasi tidak membuat file baru?

Salinan hanya dibuat jika hasil yang sudah diperiksa lebih kecil. «Tidak berkurang» berarti file asli dipertahankan. Kompresi sebelumnya, format, dan persyaratan lossless dapat menghalangi pengurangan.

Apakah kualitas 50% berarti ukuran file setengahnya?

Tidak. Kualitas mengatur kompresi ulang lossy yang didukung, bukan target ukuran. Optimasi PNG dan TIFF mempertahankan piksel yang telah didekode.

Mengapa alur kerja meminta izin folder?

macOS mengatur akses file dan folder. Alur Finder yang memakai folder yang sama mungkin meminta Anda memilihnya sekali. ImageMorph mengingat izin yang masih berlaku; perubahan izin dapat memerlukan persetujuan ulang.

Di mana detail hasil dapat dilihat?

Buka Riwayat untuk hasil dan kesalahan masing-masing. Arahkan penunjuk ke pesan kesalahan yang dipersingkat untuk membaca semuanya. Kesalahan tersimpan dapat mempertahankan bahasa asal.

Bagaimana pembelian dan pemulihan Studio bekerja?

Studio membuka PDF Studio, Icon Studio, OCR & Codes, Code Studio, alur kerja, folder yang dipantau, dan Tindakan Cepat Finder, termasuk pengambilan kode dari kamera atau pemindai yang kompatibel. Ini pembelian dalam aplikasi satu kali, tidak habis pakai, melalui Apple. Gunakan Beli atau Pulihkan Pembelian dengan Akun Apple yang digunakan saat membeli. Kelayakan uji coba diperiksa terpisah oleh layanan online. Hubungi dukungan bila akses belum diperbarui.

Bolehkah mengirim file contoh untuk laporan bug?

Mulailah dengan pesan kesalahan dan langkah reproduksi. Bila perlu, gunakan contoh kecil yang tidak sensitif dan boleh Anda bagikan. Mengirimnya lewat email berbeda dari pemrosesan lokal aplikasi.

Sebelum menghubungi dukungan

  • Periksa entri individual pada Riwayat.
  • Catat format sumber, operasi, dan folder hasil.
  • Coba file kecil tanpa data sensitif.
