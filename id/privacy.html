Pemrosesan lokal

Konversi gambar, optimasi, pembuatan PDF dan OCR berlangsung di Mac. Isi file tidak dikirim ke layanan uji coba Studio. Izin diperlukan untuk file, folder, kamera dan pemindai; pengaturan, riwayat, bookmark serta log nama, lokasi dan kesalahan dapat tersimpan lokal.

Pembelian Studio

Pembelian dan pemulihan Studio menggunakan StoreKit serta App Store. Aplikasi menerima informasi transaksi dan hak akses, bukan kata sandi Apple atau data kartu Anda.

Kelayakan uji coba

Saat uji coba diaktifkan, transaksi aplikasi bertanda tangan Apple dan versi permintaan dikirim melalui HTTPS. Layanan menggunakan ID transaksi terkait akun, identitas aplikasi dan lingkungan Store untuk memeriksa kelayakan; ID ini tidak anonim.

Pengenal transaksi aplikasi yang ditandatangani Apple terkait dengan akun dalam konteks App Store, tetapi bukan kata sandi atau alamat email Akun Apple Anda. Layanan memeriksa transaksi, identitas aplikasi, lingkungan Store, dan versi permintaan yang dikirim.

Layanan dan catatan

Google Cloud Run mengoperasikan layanan; Apple CloudKit menyimpan catatan kelayakan dengan ID turunan berkunci server, data aplikasi, lingkungan dan tanggal uji coba. Menghapus aplikasi tidak otomatis menghapus catatan server.

CloudKit menyimpan catatan kelayakan berisi pengenal turunan dengan kunci server, ID aplikasi, lingkungan, versi catatan, serta tanggal mulai dan akhir uji coba. Pengenal ini mengenali subjek uji coba yang sama dan tidak boleh dianggap anonim. Catatan dipakai untuk memberikan dan memulihkan uji coba, menegakkan masa berlakunya serta mencegah aktivasi berulang atau manipulasi. Menghapus aplikasi tidak otomatis menghapus catatan di server.

Situs dan koneksi

Penyedia dapat memproses alamat IP, data koneksi dan log operasional atau keamanan. Situs ini dihosting di GitHub Pages tanpa skrip analitik tambahan, pelacak iklan, cookie atau font eksternal.

Permintaan online memperlihatkan alamat IP dan informasi koneksi biasa kepada penyedia layanan. Google Cloud dapat memproses log operasional dan keamanan menurut konfigurasinya; GitHub Pages mencatat IP untuk keamanan. Situs ini tidak menambahkan skrip analitik, pelacak iklan, cookie, font eksternal, atau formulir kontak tertanam.

Pesan dukungan

Jika Anda mengirim email dukungan, Gmail memproses alamat, pesan dan lampiran opsional untuk menanggapi dan meneliti masalah. Hindari file sensitif.

Penggunaan dan penyimpanan

Data digunakan untuk fungsi aplikasi, pembelian, uji coba, dukungan dan keamanan. Data tidak dijual atau digunakan untuk pelacakan iklan lintas aplikasi. Catatan uji coba dapat disimpan setelah berakhir; log dan email mengikuti kebijakan penyedia. Tidak dijanjikan jadwal penghapusan tetap.

File lokal tunduk pada pengaturan dan tindakan pengguna. Catatan kelayakan dapat disimpan setelah masa uji coba habis untuk penegakan batas dan pemulihan. Email dukungan dan log operasional disimpan sesuai kebutuhan dukungan, keamanan, kewajiban yang berlaku dan pengaturan penyedia; tidak ada janji penghapusan otomatis dengan jangka waktu tetap. Anda dapat meminta akses, perbaikan atau penghapusan melalui email; beberapa catatan mungkin harus dipertahankan. Apple menangani pembayaran dan data Akun Apple.

Pilihan Anda

Anda dapat mengelola izin macOS, menolak uji coba dan meminta akses, koreksi atau penghapusan melalui kharliux@gmail.com. Catatan keamanan tertentu mungkin perlu disimpan. Apple menangani akun dan pembayaran App Store.
