자주 묻는 질문

최적화 후 새 파일이 생성되지 않은 이유는 무엇인가요?

검증된 결과가 원본보다 작을 때만 별도 파일을 생성합니다. '크기 감소 없음'은 원본을 유지했다는 뜻입니다. 기존 압축, 파일 형식 및 무손실 조건 때문에 크기가 줄지 않을 수 있습니다.

품질 50%이면 파일 크기도 절반인가요?

아닙니다. 품질은 지원되는 손실 재압축을 제어하며 목표 파일 크기를 뜻하지 않습니다. PNG 및 TIFF 최적화는 디코딩된 픽셀을 보존합니다.

워크플로가 폴더 접근 권한을 요청하는 이유는 무엇인가요?

macOS가 파일과 폴더 권한을 관리합니다. 같은 폴더를 사용하는 Finder 워크플로에서 최초 선택을 요구할 수 있습니다. ImageMorph는 유효한 권한을 기억하지만 권한이 바뀌면 다시 선택해야 할 수 있습니다.

결과 세부 정보는 어디에서 볼 수 있나요?

기록에서 개별 결과와 오류를 확인하세요. 짧아진 오류 메시지 위에 포인터를 올리면 전체 내용을 볼 수 있습니다. 저장된 오류는 생성 당시 언어로 남을 수 있습니다.

Studio 구매와 복원은 어떻게 하나요?

Studio는 PDF Studio, Icon Studio, OCR & Codes, Code Studio, 워크플로, 감시 폴더, Finder 빠른 동작을 잠금 해제하며 호환 카메라와 스캐너를 통한 코드 캡처도 지원합니다. Apple이 관리하는 일회성 비소모성 앱 내 구입입니다. 구입에 사용한 Apple 계정으로 구입 또는 구입 항목 복원을 사용하세요. 체험 자격은 별도 온라인 서비스가 확인합니다. 접근 권한이 갱신되지 않으면 지원팀에 문의하세요.

버그 신고에 예제 파일을 보낼 수 있나요?

먼저 오류 메시지와 재현 단계를 알려 주세요. 필요한 경우 공유 권한이 있는 작고 민감하지 않은 파일만 보내세요. 이메일 첨부는 앱의 로컬 처리와 별개입니다.

지원팀에 문의하기 전에

  • 기록에서 해당 항목을 확인하세요.
  • 원본 형식, 작업, 출력 폴더를 적어 두세요.
  • 민감한 정보가 없는 작은 파일로 재현해 보세요.
