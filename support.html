Frequently asked questions

Why did optimization create no file?

Optimization creates a separate output only when the validated result is smaller. A “No reduction” result means the original was kept and no optimized copy was created. Existing compression, format and lossless requirements affect what can be saved.

Does 50% quality mean a file half the size?

No. Quality controls supported lossy recompression; it is not a target file-size percentage. PNG and TIFF optimization preserve decoded pixels, so quality settings do not promise the same effect for every format.

Why does a workflow ask for folder access?

macOS permissions control access to files and folders. A Same Folder Finder workflow may ask you to select the folder once. ImageMorph can remember a valid authorization; macOS changes or an invalid permission can require selection again.

Where can I see the details of a result?

Open History to review individual results and errors. Hover over a shortened error to read its full text. A saved error can remain in the language used when it was generated.

How do Studio purchases and restores work?

Studio unlocks PDF Studio, Icon Studio, OCR & Codes, Code Studio, workflows, watched-folder automation and Finder Quick Actions. Camera and compatible-scanner code capture are part of the Studio tools. Studio is a one-time, non-consumable in-app purchase managed through Apple. Use the purchase and Restore Purchases controls in ImageMorph with the Apple Account associated with your purchase. Trial eligibility is checked separately by ImageMorph’s online trial service. Contact support if access does not refresh as expected.

Can I send a sample file with a bug report?

Start with the error and reproduction steps. If a sample is needed, use a small non-sensitive example you have permission to share. Sending a file by email sends it to support; it is separate from the app’s local processing.

Before contacting support

  1. Check the individual History entry.
  2. Note the source format, selected operation and output-folder setting.
  3. Try a small non-sensitive file to see whether the issue is reproducible.
