Preguntas frecuentes

¿Por qué la optimización no creó un archivo?

Solo se genera una copia si el resultado validado ocupa menos espacio. «Sin reducción» significa que se conserva el original. La compresión previa, el formato y los requisitos sin pérdida pueden impedir una reducción.

¿Calidad del 50 % significa la mitad del tamaño?

No. La calidad controla la recompresión con pérdida cuando está admitida; no fija un porcentaje de tamaño. La optimización de PNG y TIFF conserva los píxeles decodificados.

¿Por qué un flujo pide acceso a una carpeta?

macOS controla los permisos. Un flujo de Finder que usa la misma carpeta puede pedirte seleccionarla una vez; ImageMorph recuerda la autorización mientras sea válida. Si macOS cambia el permiso, puede pedirla otra vez.

¿Dónde consulto los detalles de un resultado?

Abre Historial para ver resultados y errores individuales. Coloca el puntero sobre un mensaje abreviado para leerlo completo. Los errores guardados pueden conservar el idioma original.

¿Cómo funcionan las compras y restauraciones de Studio?

Studio desbloquea PDF Studio, Icon Studio, OCR y códigos, Code Studio, flujos de trabajo, carpetas supervisadas y acciones rápidas de Finder; también permite capturar códigos con cámaras y escáneres compatibles. Es una compra integrada no consumible de pago único gestionada por Apple. Utiliza Comprar o Restaurar compras en ImageMorph con la cuenta de Apple que compró Studio. La elegibilidad de prueba se comprueba por separado mediante el servicio online. Si el acceso no se actualiza, contacta con soporte.

¿Puedo enviar un archivo de muestra para informar un error?

Empieza por el error y los pasos para reproducirlo. Si necesitas enviar una muestra, que sea pequeña, no sensible y que tengas permiso para compartir. Enviarla por correo es distinto del procesamiento local de la aplicación.

Antes de contactar con soporte

  • Consulta la entrada individual en Historial.
  • Anota formato original, operación y carpeta de salida.
  • Comprueba si se reproduce con un archivo pequeño sin datos sensibles.
